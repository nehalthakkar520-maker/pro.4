# SMART DATA ANALYZER

## Overview

SMART DATA ANALYZER is a Python mini project that performs different operations on numerical datasets entered by the user.

This project helps beginners understand important Python concepts such as:

- Functions
- Recursion
- Lambda Functions
- Global Variables
- *args and **kwargs
- Loops and Conditions
- List Operations

---

# Functions Used

## 1. show_data(data)
Displays all entered data.

## 2. calculate_average(data)
Calculates the average of the dataset.

## 3. find_max_min(data)
Finds maximum and minimum values.

## 4. remove_duplicates(data)
Removes duplicate values from data.

## 5. sort_data(data)
Sorts data in ascending order.

## 6. lambda_filter(data)
Filters values greater than 50 using lambda function.

## 7. fibonacci(n)
Generates Fibonacci numbers using recursion.

## 8. dataset_summary(data)
Displays total values and sum using global keyword.

## 9. show_args(*args)
Demonstrates use of *args.

## 10. show_kwargs(**kwargs)
Demonstrates use of **kwargs.
